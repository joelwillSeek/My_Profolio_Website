# My Personal Profile Page

Welcome to the repository for my personal profile page! This site serves as an online resume and portfolio, showcasing my skills, projects, and ways to get in touch.

---

### 🚀 Technologies Under the Hood

This profile page is built with a modern, efficient, and popular tech stack:

- **Vite**: My go-to build tool for a blazing-fast development experience and optimized production builds.
- **React**: The powerful JavaScript library that makes building interactive user interfaces a joy, allowing for a component-based and efficient structure.
- **Yarn**: My preferred package manager for managing project dependencies – it's fast, reliable, and secure.
- **Tailwind CSS**: A fantastic utility-first CSS framework that let me style the entire site quickly and responsively, directly in the markup.

### 🌐 Live on Netlify!

This profile page is deployed and hosted on **Netlify**. That means every time I push an update to the `main` branch of this GitHub repository, Netlify automatically triggers a new build and deploys the latest version live to the web. It's truly continuous deployment at its finest!

### ⚙️ Getting Started (For Developers)

Want to run this project locally or explore the code? Here's how you can get it set up:

1.  **Clone the repository:**
    ```bash
    git clone My_Profolio_Website # Replace with your actual repo URL
    cd My_Profolio_Website # Navigate into the cloned directory
    ```
2.  **Install dependencies:**
    ```bash
    yarn install
    ```
3.  **Start the development server:**

    ```bash
    yarn dev
    ```

    Your browser should automatically open to `http://localhost:5173` (or a similar port) where you can see the application running.

4.  **Build for production (optional):**
    ```bash
    yarn build
    ```
    This command compiles and optimizes the project for deployment, placing the final files in the `dist` directory.
